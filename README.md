# SWYNEX Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a cleaned sales dataset using Python and Pandas.

The analysis focuses on identifying important sales patterns and business insights from the dataset.

## Dataset

The dataset contains 2,000 sales records with the following columns:

- order_id
- order_date
- customer_name
- city
- state
- category
- product
- quantity
- sales
- discount

## Tools & Technologies

- Python
- Pandas
- GitHub

## Key Insights

1. **Highest Sales Category:** Clothing — ₹15,830,459.86
2. **Highest Sales State:** Maharashtra — ₹12,555,567.92
3. **Top-Selling Product:** Notebook — ₹3,592,701.67
4. **Highest Sales Month:** March — ₹7,038,286.66
5. **Highest Average Discount Category:** Electronics — 12.98%
